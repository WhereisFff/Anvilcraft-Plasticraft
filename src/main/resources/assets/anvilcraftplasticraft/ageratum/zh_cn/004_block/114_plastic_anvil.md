# 塑料铁砧

<recipe id="anvilcraftplasticraft:plastic_anvil"/>

# 功能

- 手持<ref item="anvilcraftplasticraft:plastic_anvil"/>右击地面，会放置一个实体塑料铁砧。
- 实体拥有完整方块大小的硬碰撞箱，可以被玩家和其他可推动实体推动；它不是下落方块，也不会因为重力下落。
- 右击已经放置的实体，可以打开普通皇家铁砧修复界面。
- 界面支持原版铁砧的修复、重命名和附魔合并流程；使用界面不会损坏实体铁砧。
- 物品已经保存塑料颜色，为以后增加不同颜色的塑料铁砧预留接口；模型和 Jade 信息也会显示对应颜色。

当前的雪球配方只是临时方案。后续版本会用更完整的塑料工艺替换它。
