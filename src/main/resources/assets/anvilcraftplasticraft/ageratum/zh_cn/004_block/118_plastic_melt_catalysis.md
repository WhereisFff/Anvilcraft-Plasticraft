# 通用塑料熔体与皇家钢、浮霜金属催化

塑料油转化为通用塑料熔体是一种环境反应，而不是配方。只要塑料油、皇家钢或浮霜金属制品和有效热源在同一装置中正确接触，反应就会自动推进，因此 JEI 中没有独立的催化压制配方。

## 开放催化

把带有 `anvilcraftplasticraft:royal_steel_items` 或 `anvilcraftplasticraft:frost_metal_items` 标签的物品放进塑料油，并让热源紧贴载体正下方。下列载体均可反应：

- 装有塑料油的四层炼药锅；
- 鱼缸；
- 大型炼药锅；
- 开口朝上的硬化树脂炼药锅；
- 世界中的塑料油流体源。

皇家钢和浮霜金属都不会被消耗。每种材料各自按不同物品 ID 的数量计算，同一种物品放入多件仍只算一种。放入 `n` 种皇家钢时，开放反应倍率为 `M(n) = 0.25 + log2(n) / 12`，最高为 0.55：一种皇家钢物品是密封压盖速度的 1/4，八种不同物品恰好为 1/2。

同种数量的浮霜金属始终只有对应皇家钢倍率的一半：一种为密封压盖速度的 12.5%，八种为 25%。浮霜金属保留了皇家钢的魔力，但低温会抵消一部分外部热源。混用时倍率为 `M(R) + 0.5 * (M(R + F) - M(R))`，其中 `R` 和 `F` 分别是皇家钢与浮霜金属的不同物品种类数。因此每种浮霜金属只提供新增皇家钢种类一半的速度，且不会降低已有皇家钢的速度。

热源沿用集热器可识别的热源，以及工作中的燃烧加热器和电加热器。不同热源保留各自的实际热功率，不会被统一替换成某一种热源。

## 大型炼药锅

大型炼药锅读取锅底正下方 3×3 的九个位置，最终热功率为九格实际功率之和除以 9。九格放满同一种热源时与鱼缸使用该热源的速度相同；只有一格时速度为对应鱼缸的 1/9；混合热源则按每一格各自的功率共同计算。一次完成会转化锅中整层塑料油，因此它可以批量处理最多 64 B。

## 催化压盖

催化压盖本身提供皇家钢催化面。用高粘性树脂把它粘在兼容容器正上方并从下方加热时，不需要再把皇家钢或浮霜金属物品放进油中，反应按完整速度推进。反应完成后用下落铁砧压下压臂；熔体会优先从容器输出口或管网排出，无法排出时会冲破容器并弹起压盖。

若容器输出口正对一个装满水的原版炼药锅，压制会精确消耗 `1000 mB` 通用塑料熔体和一满锅水，并在锅的位置掉落 16 个继承熔体颜色的塑料粒。熔体不足 `1000 mB`、水锅未满或事务提交失败时，两侧资源都不会被吞掉；面对其他目标时仍沿用原有输出口和管网处理。
