# 塑料成型

塑料成型舱把可编辑的 Cube 模型制成塑料实体或塑料制品。先准备成型舱和模型，再按模型选择铸造成型或 3D 打印

2. [编辑、导入与保存模型](010_model_editor_and_import.md)
