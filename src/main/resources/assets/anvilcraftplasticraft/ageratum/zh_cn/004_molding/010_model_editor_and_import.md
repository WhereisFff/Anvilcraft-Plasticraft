# 模型编辑与导入

## 编辑 Cube

成型舱的编辑器只认 Cube：一个个方盒子拼出模型。Cube 能移动、缩放、旋转，也能按共享枢轴编成组，一组之内显示状态和锁定状态是共享的

锁定之前至少得有一个 Cube。超过当前成型方式范围的模型只能继续编辑，锁不上。零厚度平面会保留在模型里，但它不增加铸造体积

## 建模工作区

点击视口右下角的展开按钮，或按 `Ctrl+Space`，即可在机器面板与大建模工作区之间切换。大工作区中央是视口，左侧是变换工具，右侧是数值属性和层级大纲，顶部集中放置新建、重复、分组、撤销、重做、聚焦和返回操作

展开建模器只改变界面布局，模型仍保存在当前成型舱中。需要存取物料、切换生产模式或操作结构磁盘时，返回机器面板即可

## 选择与大纲

- 左键单击 Cube 选中它，按住 `Ctrl` 单击追加或取消选择，`Shift` 单击选择父组，`Ctrl+Shift` 单击追加或取消父组选择
- 按住 `Shift` 在视口拖出矩形可以框选多个 Cube
- 大纲按分组层级排列，可以折叠分组、搜索名称，并直接点击每行的显示或锁定按钮；大纲内 `Ctrl` 单击追加或取消该行，`Shift` 单击选择连续范围
- `Ctrl+A` 全选，`Ctrl+Shift+A` 反选；`Ctrl+D` 重复所选内容，`Ctrl+G` 建立分组
- `F2` 重命名，`Delete` 删除选择，`H` 显示或隐藏，`L` 锁定或解锁

隐藏控制视口中的可见性，锁定控制是否允许修改。分组状态会影响内部元素，选择分组后可一起调整其成员

## 视角与工具

在视口空白处按住左键拖动旋转视角，右键或中键拖动平移，滚轮缩放。右键单击打开操作菜单；变换轴控制的是模型，视口空白拖动控制的是相机

| 操作 | 快捷键 |
| --- | --- |
| 移动、调整大小、旋转 | `V`、`S`、`R` |
| 移动枢轴、镜像 | `P`、`M` |
| 聚焦选择、显示整模 | `F`、`Home` |
| 正面、右面、顶面 | `1`、`3`、`7`，也支持小键盘 |
| 背面、左面、底面 | 对应视角键同时按住 `Ctrl` |
| 透视视图 | `5`，也支持小键盘 |
| 新建 Cube | `N` |
| 撤销、重做 | `Ctrl+Z`、`Ctrl+Shift+Z` 或 `Ctrl+Y` |
| 复制、剪切、粘贴 | `Ctrl+C`、`Ctrl+X`、`Ctrl+V` |

## 数值与编辑结果

右侧属性按位置、大小、枢轴、旋转分行，分别编辑 X、Y、Z 分量。位置与枢轴以制造原点为 `(0,0,0)`，大小与旋转沿元素自身的局部坐标；位置、大小与枢轴使用 px，旋转使用度，`16px` 等于一个方块

编辑数值时，`Enter` 提交，`Esc` 取消，`Tab` 与 `Shift+Tab` 在数值格之间移动。数值输入支持加、减、乘、除和括号，例如 `8/2` 将属性设为 `4`。以 `+`、`*`、`/` 或 `-=` 开头的输入会分别作用于每个所选对象的原值，例如 `+1`、`*2`、`/2`、`-=1`；直接输入 `-2` 则设为负二。多选对象的同一属性不相同时显示混合值

数值格上滚动滚轮可步进调整。移动、大小与枢轴默认步长为 `1px`，按住 `Shift` 为 `0.1px`，按住 `Ctrl` 为 `10px`；旋转默认 `15°`，`Shift` 为 `1°`，`Ctrl` 为 `45°`。拖动变换轴使用同样的吸附步长，按住 `Alt` 可临时取消吸附

拖动变换轴时可以实时查看形状，松开后提交本次修改。调整枢轴不会移动已有几何；多选旋转绕同一个选择中心进行，镜像保留元素的加材或减材属性

不同朝向的多选元素不能共用尺寸拖拽，应分别选择调整；父组非均匀缩放造成无法表示的剪切变形时也会拒绝修改。锁定元素或锁定组内的元素不会被变换，混合选择中的锁定项也不会被删除

撤销和重做作用于模型编辑历史；相机旋转、平移和缩放不改变模型

## 结构磁盘

编辑器的磁盘槽只接受 AnvilCraft 的 <ref item="anvilcraft:structure_disk"/>。加载磁盘会把里面的成型模型复制进编辑器，进来之后照样能改；存入磁盘则是保存当前模型的一份副本

成型模型与本体结构使用同一种结构磁盘，但一张磁盘只保留一种内容。保存模型覆盖已有磁盘内容时需要再次确认；若磁盘由本体重新写入结构，则优先按本体结构处理，不会误加载残留的成型模型

手持成型磁盘潜行右击空气可以清空该磁盘，主手与副手都适用；这不会删除共享模型，也不会改变之前复制的其他磁盘

## 共享模型库

世界会把共享 `.json` 模型存在 `anvilcraftplasticraft/blueprints/` 下，上限 512 个；结构磁盘那边还留着一份能独立载入的副本。共享模型可以载入、复制和重命名，而且删除共享文件不会影响已经写入磁盘或已经载入成型舱的副本

## 从模型文件夹导入

在模型管理里打开模型文件夹，把不超过 1MiB 的 Minecraft Java `.json` 或 Blockbench `.bbmodel` 丢进去，回来刷新一下就能看到。Cube、分组、枢轴和支持的旋转都能进来；贴图、动画和显示变换不会进入成型模型，实在无法转换的非 Cube 几何会被拒绝

导入时超出成型范围的模型不会被缩放塞进去，它仍然能保存、载入和编辑，只是锁不上、加工不了。尺寸符合范围但整体偏离工作空间的模型会先给你一个整体平移建议，确认之后才按该位移导入
