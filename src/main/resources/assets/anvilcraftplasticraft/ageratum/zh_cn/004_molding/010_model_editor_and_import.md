# 模型编辑与导入

## 编辑 Cube

成型舱编辑器以 Cube 组成模型。Cube 可以移动、缩放、旋转并按共享枢轴分组，分组也会共享显示和锁定状态

锁定前必须至少有一个 Cube。超过当前成型方式范围的模型只能继续编辑；零厚度平面会保留在模型中，但不增加铸造体积

## 结构磁盘

编辑器的磁盘槽只接受 AnvilCraft 的 <ref item="anvilcraft:structure_disk"/>。加载磁盘会把其中的成型模型复制到编辑器并保持可编辑，存入磁盘会保存当前模型副本。成型模型和施工结构使用同一种磁盘物品但不能同时存放，施工投影也不能直接当作成型模型加工

## 共享模型库

世界会在 `anvilcraftplasticraft/blueprints/` 下保存共享 `.json` 模型，最多 512 个；结构磁盘同时保留可独立载入的副本。共享模型可载入、复制和重命名，删除共享文件不会影响已经写入磁盘或载入成型舱的副本

## 从模型文件夹导入

在模型管理中打开模型文件夹，放入不超过 1MiB 的 Minecraft Java `.json` 或 Blockbench `.bbmodel`，再刷新模型。可导入 Cube、分组、枢轴和支持的旋转；贴图、动画和显示变换不会进入成型模型，无法转换的非 Cube 几何会被拒绝

导入超出成型范围的模型不会缩放，仍可保存、载入和编辑，但不能锁定加工。符合范围但整体偏离工作空间的模型会先给出整体平移建议，确认后按该位移导入
