# 模型编辑与导入

## 编辑 Cube

成型舱的编辑器只认 Cube：一个个方盒子拼出模型。Cube 能移动、缩放、旋转，也能按共享枢轴编成组，一组之内显示状态和锁定状态是共享的

锁定之前至少得有一个 Cube。超过当前成型方式范围的模型只能继续编辑，锁不上。零厚度平面会保留在模型里，但它不增加铸造体积

## 结构磁盘

编辑器的磁盘槽只接受 AnvilCraft 的 <ref item="anvilcraft:structure_disk"/>。加载磁盘会把里面的成型模型复制进编辑器，进来之后照样能改；存入磁盘则是保存当前模型的一份副本

成型模型和施工结构共用这种磁盘物品，但一张磁盘不能同时存放两样，施工投影也不能直接当作成型模型加工

## 共享模型库

世界会把共享 `.json` 模型存在 `anvilcraftplasticraft/blueprints/` 下，上限 512 个；结构磁盘那边还留着一份能独立载入的副本。共享模型可以载入、复制和重命名，而且删除共享文件不会影响已经写入磁盘或已经载入成型舱的副本

## 从模型文件夹导入

在模型管理里打开模型文件夹，把不超过 1MiB 的 Minecraft Java `.json` 或 Blockbench `.bbmodel` 丢进去，回来刷新一下就能看到。Cube、分组、枢轴和支持的旋转都能进来；贴图、动画和显示变换不会进入成型模型，实在无法转换的非 Cube 几何会被拒绝

导入时超出成型范围的模型不会被缩放塞进去，它仍然能保存、载入和编辑，只是锁不上、加工不了。尺寸符合范围但整体偏离工作空间的模型会先给你一个整体平移建议，确认之后才按该位移导入
