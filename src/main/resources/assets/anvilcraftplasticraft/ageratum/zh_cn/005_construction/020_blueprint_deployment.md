# 蓝图部署与结构磁盘

<row halign="center">
<item id="anvilcraft:structure_disk"/>
</row>

结构磁盘可以保存施工蓝图或塑料成型模型。施工蓝图保留方块、方块实体、流体和实体；成型模型的编辑方式见[模型编辑与导入](../004_molding/010_model_editor_and_import.md)

## 导入

三种方法都会写入手中的结构磁盘：

- 手持磁盘右击已保存模板的原版结构方块
- 右击带扫描器数据的磁盘，把扫描结果转换为蓝图
- 潜行右击磁盘，在游戏目录 `anvilcraftplasticraft/structures` 中导入文件

文件导入支持原版或 Create 的 `.nbt` 和 Litematica 的 `.litematic`，可读多区域、方块实体和实体。限制为单轴 512 格、方块条目 2,097,152 个、实体条目 4,096 个、文件 8MiB

## 部署工具

手持已导入的磁盘右击，投影会跟随准星；再次右击执行当前工具。普通滚轮仍切换快捷栏，`Ctrl+滚轮`切换工具，`Alt+滚轮`调整工具：

| 工具 | 操作 |
| --- | --- |
| 移动锚点 | 右击切换跟随或锁定；未锁定时调整高度，锁定后沿最近轴移动一格 |
| 旋转 | 右击或调整参数，顺时针旋转 90 度 |
| 镜像 | 在无镜像、左右镜像、前后镜像之间循环 |
| 上一层/下一层 | 逐层查看，越过边界回到全览 |
| 确认 | 提交位置、旋转和镜像，生成施工任务 |
| 取消 | 删除该磁盘的已部署投影 |

整份投影必须位于当前维度的可建造范围内，并且不能与另一份蓝图重叠。确认后仍可在任务启动前重新调整；任务启动后，锚点便不能移动

施工阶段和资源处理见[施工任务](030_construction_jobs.md)
