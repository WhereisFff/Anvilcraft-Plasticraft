# 蓝图部署与结构磁盘

<row halign="center">
<item id="anvilcraft:structure_disk"/>
</row>

一张结构磁盘能装施工蓝图，也能装塑料成型模型。施工蓝图会连方块、方块实体、流体和实体一起保留；成型模型那边的编辑方式见[模型编辑与导入](../004_molding/010_model_editor_and_import.md)

鼠标悬停在施工蓝图或扫描器结构磁盘上可查看旋转缩略图。首次查看大结构时，底部进度条表示预览生成进度，模型会逐步显示；生成完成后持续悬停会复用预览。缩略图用于查看方块外观，方块实体数据和实体的完整保存不受预览影响

## 导入

三种办法都会写进你手上的结构磁盘：

- 手持磁盘右击已保存模板的原版结构方块
- 右击带扫描器数据的磁盘，把扫描结果转换为蓝图
- 潜行右击磁盘，从游戏目录 `anvilcraftplasticraft/structures` 里导入文件

文件导入吃得下原版或 Create 的 `.nbt`，以及 Litematica 的 `.litematic`，多区域、方块实体和实体都能读。上限是单轴 512 格、方块条目 2,097,152 个、实体条目 4,096 个、文件 8MiB

## 部署工具

手持已导入的磁盘右击，投影就跟着准星走；再右击一次执行当前工具。普通滚轮仍然切换快捷栏，`Ctrl+滚轮`换工具，`Alt+滚轮`调工具参数：

| 工具 | 操作 |
| --- | --- |
| 移动锚点 | 右击切换跟随或锁定；未锁定时调整高度，锁定后沿最近轴移动一格 |
| 旋转 | 右击或调整参数，顺时针旋转 90 度 |
| 镜像 | 在无镜像、左右镜像、前后镜像之间循环 |
| 上一层/下一层 | 逐层查看，越过边界回到全览 |
| 确认 | 提交位置、旋转和镜像，生成施工任务 |
| 取消 | 删除该磁盘的已部署投影 |

整份投影必须位于当前维度的可建造范围内，而且不能和另一份蓝图重叠。确认之后、任务启动之前你还可以重新调整；任务一启动，锚点就钉死了

施工阶段和资源处理见[施工任务](030_construction_jobs.md)
