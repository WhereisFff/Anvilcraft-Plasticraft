# 铁砧工艺：塑料工艺 26.8 正式版更新日志

> 发布日期：2026-08-31  
> 适用版本：Minecraft 1.21.1 / NeoForge 21.1  
> 变更范围：`39adc38..a897a8b`，42 个提交，2026-08-02 至 2026-08-31  
> 本文按 26.8 分支创建后的实际代码、资源、数据和测试整理；未把 26.7 基线以前的改动计入本版

26.8 是 Plasticraft 的一次完整纵向扩展：从可编辑塑料模型、铸造与 3D 打印，延伸到四种功能塑料、可移动功能制品，以及由戴帽悦灵执行的蓝图施工、拆除和物流。与此同时，动态制品碰撞、存档恢复、投影同步和大结构性能完成了系统级收尾。

## 重点内容

- **塑料成型生产线**：加入塑料成型舱、嵌入式模型编辑器、共享蓝图库、结构磁盘、铸造和 3D 打印
- **四种塑料材料**：通用、工程、透明、耐热塑料及其熔体、粒料、桶、方块、实体和十六色变体
- **功能制品**：箱子、储罐、炼药锅、大型炼药锅、塑料铁砧、红石支架和悦灵安全帽
- **蓝图施工**：支持原版结构、Create 和 Litematica 导入；施工任务可封堵流体、真实拆除、回收掉落并提交结构
- **施工悦灵**：安全帽把普通悦灵转换为 `working_allay`，主手工具决定建设、拆除、收集或观察能力
- **物理与稳定性**：真实凸体 SAT 碰撞、24 向姿态、落地事件、活塞/滑轨/粘接联动、重启恢复和大型结构优化

## 新增与扩展

### 1. 塑料成型舱与模型工作流

- 新增塑料成型舱及 3×3×3 成型区域，支持四个水平朝向的原子放置、结构修复、整体拆除和区域碰撞
- 内置 48×48×48 px 模型工作空间，编辑器支持 Cube、零厚度面、分组、锁定、移动、缩放、旋转、共同枢轴、数值变换、撤销/重做和只读查看
- 服务端权威编辑会话加入单写者租约、心跳、接管、修订号、快照和增量同步，保证多人编辑不会互相覆盖
- 共享模型库以内容寻址保存，支持搜索、置顶、复制、重命名、删除、导入和权限校验；共享库上限 512 个模型
- 支持 Minecraft Java JSON、Blockbench `.bbmodel`、Plasticraft JSON，以及结构磁盘自包含副本；超范围模型可以保存和编辑，但不能锁定加工
- 模型导入加入 1 MiB 文件大小、路径、符号链接、嵌套深度、元素数、分组数、轴向尺寸和坐标校验；不再静默接受无法转换的几何
- 允许用多相超限合金在本周期绕过制品类型形状校验，但不绕过铸造/打印尺寸限制；类型验证、预览、部分成型和失败提示统一收口
- 结构磁盘槽仅接受 AnvilCraft 结构磁盘；成型模型和施工蓝图共用物品但不能同时存放

### 2. 铸造、3D 打印与生产控制

- 成型舱固定使用 256 kW，内部最多 160,000,000 FE；可通过满电或空的超级电容器合成并继承电量
- 暂存熔体容量 8 B（8000 mB），满足条件时每 gt 最多泵送 250 mB；一件制品按每 4 个体素支付 1 mB，最低消耗 250 mB
- 铸造使用三层粘土模具，锁定后 12 gt 完成；粘土按每 1024 个空余体素 1 个粘土球计算，成型区域会自动收集周围 5×5×5 范围内的粘土球（每 40 gt 一次）
- 熔体、粘土、能源、占用和输出预检采用原子事务；材料不足、区域阻塞、实体生成失败、重载或中断都会保留或完整退还正确资源
- 三种生产模式：连续加工、红石上升沿控制、单次加工；锁定、加工、出料期间切换模式会作用于下一周期
- 3D 打印组件安装在成型舱正上方后切换打印模式；打印按 Y 分层、X 换行、Z 往返的蛇形路径执行，每 gt 最多消耗 1 mB
- 打印组件拥有独立 8192 mB 批次储量、三轴打印头、双舱门、移动/加工/归位动画和持久化进度；完成后直接生成完整实体，不经过粘土和落砧平台
- 打印工作区限制为 X/Z 8..40 px、Y 1..33 px；出料时释放重力，等待制品离开区域后才关门，期间禁止新的周期抢占输出区
- 铸造平台规则固定为：3×3 工作台生成塑料实体；外围八格工作台加中心空间超压器生成塑料制品物品
- 新增并统一以下成型类型：`normal`、`chest`、`tank`、`anvil`、`cauldron`、`large_cauldron`、`tray`、`allay_hard_hat`

### 3. 动态塑料制品

- 制品以实体形式存在，支持重力、浮力、磁力、推动、滑轨、活塞、粘接、回收、放置和重载；所有模型保留材料、颜色、名称、姿态和功能数据
- 任意方块面均可放置，每个面有四种面内转角，共 24 种姿态；铁砧锤可在实体或方块化状态下调整方向
- 物品栏、实体、锤击预览和粘合方块态共用真实表面网格、实际边界和碰撞凸体；真实几何用于站立、跨步、推动、选取、准星高亮和 F3+B
- 零厚度面可以选取和回收，但不承托、不阻挡实体；动态制品物品栏按可见表面中心和最大边长统一占幅，Tooltip 显示实际三轴尺寸
- 物品创造复制区分空白初始制品和带内容复制：普通中键只复制形状与材料，Ctrl+中键才复制可保存功能状态

#### 材料属性

| 材料 | 染色 | 方块硬度 / 爆炸抗性 | 本版能力 |
| --- | --- | ---: | --- |
| 通用塑料 | natural + 16 色 | 1.5 / 3.0 | 基础塑料行为 |
| 工程塑料 | natural + 16 色 | 2.5 / 6.0 | 更坚固；工程制品支持精准采集拆除 |
| 透明塑料 | natural + 16 色 | 1.5 / 3.0 | 激光穿透；制品可为信标光柱着色 |
| 耐热塑料 | natural + 16 色 | 3.5 / 10.0 | 防火；耐热制品支持熔炼掉落拆除并免疫激光伤害 |

- 四种熔体、粒料、桶、方块、实体和成型批次统一传递材料与颜色；熔体可用冷却物或水/细雪冷却，每 1000 mB 产出 16 个同色粒料
- 熔体世界源遇雨、水、冰或雪可直接凝固为对应材料的特殊制品；塑料油、通用熔体、工程熔体、耐热熔体和透明熔体的催化链全部接入配方与 JEI
- 塑料油与通用熔体可使用皇家玻璃、浮霜玻璃、皇家钢、浮霜金属和余烬金属推进不同材料分支，并按寒冷、加热、冷却、染色和凝固条件结算
- 透明塑料加入透明面剔除、延迟渲染、激光穿透和信标染色；工程塑料加入精准采集；耐热塑料加入火焰免疫、激光免疫和熔炼拆除

#### 功能制品类型

- **箱子**：每 64 个内腔体素提供 1 个物品槽，无额外菜单，漏斗/溜槽可直接传输
- **储罐**：每 171 个内腔体素提供 1 B 总容量，支持多流体、管道和手持容器；所有材料都能储存熔岩
- **普通塑料炼药锅**：顶部开口至少 144 px²、内腔深度至少 8 px，容量为 `max(1, floor(内腔体积 ÷ 1728))` B，提供 8 个输入槽和 8 个输出槽
- **大型塑料炼药锅**：开口超过 1600 px² 时自动升级，固定 512 B、8 层流体、8 个输入槽、32 个输出槽，单次落砧最多 9 条配方通道
- **塑料铁砧**：底面至少 12×12 px、总高至少 10 px；底面达到 40×40 px 时解锁巨型铁砧、多方块加工、撼地和大型炼药锅处理
- **红石支架**：48×48 px、最高 4 px，最多 9 个元件；支持红石火把、按钮、拉杆、压力板、阳光探测器、中继器、比较器、高级比较器、脉冲发生器和物品探测器
- **悦灵安全帽**：模型占地不超过 11×11 px、高度不超过 16 px，必须使用 3D 打印组件；工程帽提供精准采集，耐热帽提供火焰免疫和熔炼拆除

### 4. 树脂、炼化与粘接

- 完善树脂铁砧、硬化树脂铁砧、树脂铁砧锤、高粘性树脂和树脂胶的实体、方块化、运输、捕获、回收及重载状态
- 树脂胶预览与确认改为服务端权威异步流程，加入起点校验、路径回贴、碰撞复核、终点高亮和隐身药水隐藏状态持久化
- 胶粘的 `DESTROY` 方块可参与活塞和滑轨结构，粘接到滑轨的方块组不会被滑轨误判为载荷；传送门不会错误转换塑料实体
- 冷凝塔迁移到新的多方块定义和状态谓词 API，保留管道轴向、阀门、端部、水浸状态及铜活板门约束
- 冷凝链支持气态原油、气态水和气态经验；每 50 mB 气态原油在前三层分别冷凝为 10 mB 高热燃料、30 mB 塑料油和 10 mB 原油精华，并继续接入普通/强化等离子喷流
- 配方层迁移到 AnvilCraft 公开流体 API，虚拟气体使用独立输出字段，染色配方、流体网络、蒸汽能力和 JEI 绘制逻辑同步调整
- 流体纹理统一迁移到 `textures/fluid`，同步图集、动态纹理和生成资源引用

### 5. 蓝图、投影与施工任务

- 结构磁盘支持三种导入入口：结构方块模板、结构扫描器数据、游戏目录文件
- 支持原版结构 `.nbt`、Create `.nbt` 和 Litematica `.litematic`；保留方块状态、方块实体 NBT、实体、锚点、旋转和镜像
- 导入器统一规范化调色板、YZX 方块顺序、实体排序和 SHA-256 内容哈希；未知内容、损坏字段、区域重叠和无法映射扩展会明确报告
- 导入限制：单轴最多 512 格、方块条目最多 2,097,152、实体条目最多 4,096、上传文件最多 8 MiB，超限在分配内存前拒绝
- 部署会话提供移动、旋转、镜像、上一层、下一层、确认和取消七项工具；部署前检查世界边界与任务重叠，已有实际进度后锚点锁定
- 部署会话支持 `Ctrl+滚轮` 切换工具、`Alt+滚轮` 调整当前工具，普通滚轮继续切换快捷栏；投影按 16³ 区块段异步烘焙和分块同步
- 投影采用按区块段保存的服务端索引；已交付格提供目标碰撞，未交付格仅预览，空碰撞状态不会制造假碰撞，实体不会被封进新增碰撞
- 方块实体内容、桶装流体、分层锅流体、船、刷怪蛋、树脂捕获对象、塑料实体、多方块核心和红石导线均有专用施工适配器
- 施工阶段严格为：**流体封堵 → 真实拆除 → 掉落物回收 → 材料交付与投影 → 安静提交**；取消保留已交付结果并返还在途材料，不做世界回滚
- 拆除遵循 AnvilCraft 普通铁砧砸中切石机的掉落、经验、方块实体和多方块移除语义；基岩等永久障碍跳过，不阻塞其它位置
- 掉落物带任务 UUID 标记；收集悦灵只领取本任务掉落，玩家或漏斗提前拿走的物品记为外部结算，不会重复补发
- 告示牌和悬挂告示牌拆为安全的装饰提交步骤，支持书写、染色、发光和打蜡，并清除可执行点击事件
- 每名玩家同时最多运行一份任务，每份任务最多使用 64 只悦灵；大结构安静提交每刻最多写入 4096 格
- 施工持续监听蓝图声明格的真实世界变化：匹配目标直接满足，不匹配方块重新进入拆除流程；无法抵达的位置经过 4 次确认失败后退避 200 tick 并重试，不会错误收敛为完成

### 6. 施工悦灵与休息室

- 手持成型类型 `allay_hard_hat` 的塑料制品右击原版悦灵即可转换为唯一实体 `working_allay`；潜行右击摘帽并保留 UUID、位置、名称和主手
- 施工悦灵继承原版悦灵外观和飞行动画，关闭原版拾取/复制；碰撞箱为 0.35×0.6，无硬碰撞但可被推挤、拴绳，不使用 FE
- 工种只由主手物品解析：

| 主手 | 能力 | 触及/范围 |
| --- | --- | ---: |
| 空手或未知物品 | 普通建设、临时封堵、近距收集 | 建设 1 格；收集需到达目标 |
| 蟹钳 | 建设、封堵、携带大型制品和多方块 | 4 格 |
| 切石机 | 瞬间真实拆除 | 1 格 |
| 磁铁 | 自由拾取或任务掉落回收 | 16 格；九格临时库存 |
| 望远镜 | 观察和区块加载 | 自身为中心 |

- 新增悦灵休息室：最多托管 16 条记录、1 个结构磁盘槽；顶部入库/出库共用单通道，每 20 gt 处理 1 只，不耗电
- 结构磁盘放入休息室只认领任务；空手右击才启动或暂停。下方容器提供材料和卸货端，创造板条箱可无限供料
- 休息室提供“暂停等待/跳过”和“拆除整个区域/保留蓝图空白格”两组策略；已认领任务实时保存所有者、设置、磁盘、托管悦灵和在途物品
- 观察悦灵以自身区块为中心维持水平 3×3 共九个完整高度区块柱；休息室内符合资格的望远镜悦灵也能维持同样覆盖，区块票在交接和重启时不丢失
- 同维度休息室可组成每段不超过 128 格的转运链；远程悦灵以客工身份到达协调室，不占托管位和顶部通道，任务结束沿链返回
- 远程调度根据在场/在途工人、剩余操作、跳数和距离估算 ETA，仅在确实缩短工期时借调；施工系统 TODO 01–16 的代码与自动化验证已完成
- FTB Teams 为可选集成；未安装时仅所有者可管理，安装后所有者和当前同队成员共享蓝图、悦灵和物流权限，团队变化会在派发和世界交互前重新校验
- 多层寻路结合直线扫掠、区块段走廊和局部三维 A*，加入接近位、撤离段、交通预约、动态碰撞重规划、防自封、脱困和确定性避让

### 7. 创造栏、显示与整合

- 接入 AnvilLib 通用变体选择器；塑料创造分类页支持十六色代表格折叠、右击选择器、材料横幅展开/收起和客户端配置
- 更新成型舱、打印组件、休息室、悦灵安全帽、塑料实体、流体液面、透明材质、红石支架和投影的模型、贴图、粒子、按钮及语言资源
- JEI、Jade、Ageratum、FTB Teams 均保持独立可选集成；公共入口不直接初始化可选客户端 API
- Ageratum 中英文手册重组为流程、树脂、炼化、塑料、成型和施工章节；Tooltip、Jade 状态和 README 与当前行为同步

## 稳定性与性能

- 所有塑料实体和动态制品统一使用真实模型 Cube 生成的凸体 SAT；支持斜面穿越、落地、跨步、支撑、侧推、粘合方块态和旋转姿态
- 成型制品加入静止休眠、世界变更唤醒、支撑探针修正、朝向解码修正和按底面实际覆盖格逐格发布 `AnvilEvent.OnLand`
- 塑料箱子和储罐内容迁移到主世界 SavedData 的 UUID 外置仓储，使用稀疏物品存储和有界摘要，取消旧的 1728 格硬上限；物品、实体、能力、Tooltip、锤回和放置共用同一句柄
- 施工进度改为按类型分桶的未完成索引，投影区段使用局部调色板与稀疏位集编码；小查询按格直查，封闭洪泛和可飞判定复用缓存
- 重启恢复保证封堵、拆除、在途材料、投影补发和分区提交不重复执行；观察票按世界级索引恢复并重新校验资格
- 注册类统一为 `Plasticraft*` 命名，删除静态通配导入；本体扩展迁移到公开 Hooks、事件和 `pushExact`，移除本地 jar 与旧渲染/测试架构
- 更新 JSpecify 编译期注解、可选集成隔离、资源分区构建校验、GameTest 覆盖规范、贡献指南和 Git 忽略规则；精简中文 README 并移除重复英文 README
- 整理客户端离屏渲染边界并移除过期架构测试；动态网格、光照和材质缓存统一复用，避免逐帧重复分配

## 破坏性变更与存档提示

26.8 不提供旧存档迁移代码。升级前请备份世界，并特别注意：

- 无人机系统已整体删除并由施工悦灵取代：不再注册 `drone`、`drone_station`、`drone_data`、`station_energy`、`propeller` 及四种无人机配方；旧无人机实体、无人机站和 `LeaseDrone`/`DroneId` 进度不会迁移
- 成型类型 `propeller` 改为 `allay_hard_hat`；安全帽必须使用 3D 打印组件并遵守新的 11×11×16 px 形状限制
- `MoldedPlasticData` 最终格式为 6；格式 2 的旧制品不再支持，升级不承诺旧制品数据迁移
- 箱子和储罐内容改为 UUID 外置仓储；旧制品内嵌的 `items`/`fluids` 内容不会转换，已有内容可能需要重新制作
- `MoldedPlasticData` 的网络流只接受当前格式；不要手工伪造或跨版本复制动态制品 NBT
- 依赖已切换到 AnvilCraft/AnvilLib 公开 API 和当前快照，旧本地 jar、旧私有扩展和旧无人机相关资源不再是有效运行依赖
