# Plasticraft 材料与内容设计文档

> 状态：当前设计稿
> 适用项目：Plasticraft / AnvilCraft 附属模组
> 核心材料层级：（硬化）树脂 -> 塑料 -> 复合塑料 -> 超限塑料
> 文档目的：确定模组要提供的内容、材料特点、主线关系和现实参考。具体物品种类与配方数量可在后续内容设计中继续决定。

## 1. 设计定位

Plasticraft 的目标不是复刻完整的现实化工，而是把塑料最容易理解的特点转化为 AnvilCraft 风格的世界内玩法。

核心原则：

- **延长本体主线。** 树脂来自本体，原油来自本体，复合塑料继续使用皇家钢、余烬金属、浮霜金属、宝石光学件、超限合金和多相物质。
- **材料等级清楚。** 玩家先认识树脂，再建立原油化工和塑料加工产线，然后用本体高级材料制作复合塑料，最终进入超限塑料。
- **每种材料突出少量特点。** 游戏中只放大最重要的 1-2 个现实特性，例如弹性、透明、耐热、低摩擦或耐化学。
- **材料必须改善体验。** 提升可以来自强度、功能或舒适度，不必只表现为更高伤害、更高耐久。
- **不要求每种材料拥有完整制品套装。** 某种材料可能只有管道、容器、衬层、轴承或观察窗，不必都制作铁砧、锅、板和工具。
- **避免只为过渡存在的物品。** 产线中的可搬运材料应当同时具有加工、燃料、清洗、建筑或设备用途；否则更适合表现为锅内状态。

## 2. 材料等级与主线

### 2.1 四级材料体系

| 等级 | 核心内容 | 玩家获得的能力 | 典型内容方向 |
| --- | --- | --- | --- |
| **（硬化）树脂** | 本体树脂、树脂铁砧、硬化树脂铁砧和锅、高粘度树脂 | 早期塑料制品、弹性和黏性玩法、冷凝塔材料 | 可移动铁砧、锅、黏性流体、捕获生物、冷凝结构 |
| **塑料** | 原油冷凝产物、通用塑料、透明塑料、工程塑料、耐热塑料等 | 配混、染色、造粒、成型、回收和塑料设备 | 管、板、膜、容器、密封、衬层、观察窗、机械零件 |
| **复合塑料** | 塑料与皇家钢、余烬、浮霜、宝石光学件等结合 | 在强度、功能和舒适度上形成专门用途 | 工程结构、耐热设备、低温设备、光学件、缓冲件、电气外壳 |
| **超限塑料** | 高级复合塑料与超限合金、多相物质结合 | 终局级相态、耐久、环境适应和高阶设备能力 | 超限容器、相态部件、终局设备、少量超限工具或铁砧候选 |

材料等级表示主线位置，不表示每一级都必须有相同形态的物品。

### 2.2 主线结构

~~~text
本体树脂
  -> 树脂铁砧与硬化树脂制品
  -> 液态高粘度树脂
  -> 高粘度树脂块
  -> 冷凝塔
  -> 原油化工
  -> 塑料原料与加工产线
  -> 通用塑料及横向塑料分支
  -> 与本体高级材料结合的复合塑料
  -> 与超限合金、多相物质结合的超限塑料
~~~

主线体验应当形成三个明显变化：

1. **早期树脂阶段：** 玩家使用本体已有资源制作具有特殊物理表现的树脂制品。
2. **原油化工阶段：** 高粘度树脂块成为冷凝塔的关键材料，玩家第一次建立大型、可堆叠的塑料化工结构。
3. **材料扩展阶段：** 塑料不再只是原料，而是与本体材料结合，改善设备、工具和自动化的使用体验。

## 3. （硬化）树脂阶段

### 3.1 树脂铁砧

树脂铁砧是玩家最早接触的弹性塑料铁砧。

推荐工作台摆法：

~~~text
树脂块  树脂块  树脂块
          树脂
  树脂    树脂    树脂
~~~

主要特点：

- 是可移动、可受重力影响并可从各个方向布置的实体型铁砧。
- 不提供铁砧菜单，右键不会打开修复或附魔界面。
- 与方块或实体从任意方向相撞时都会反弹。
- 反弹应呈现“弹性很强但不会无限加速”的手感。
- 具有本体树脂块的弹性、生物捕获、保存生物、怨恨和时移等主题机制。
- 捕获普通生物时沿用本体树脂块的体型限制；敌对生物仍需要处于虚弱状态。
- 在干锅中快速烹饪后变成硬化树脂铁砧。
- 使用树脂块的蜂蜜金、半透明和柔软高光作为外观参考。
- 不支持 16 色。

树脂铁砧的定位不是普通铁砧的廉价替代品，而是一个有弹性、可搬运、可参与树脂玩法的早期工具。

### 3.2 硬化树脂铁砧

硬化树脂铁砧是最基本的塑料铁砧，也是树脂铁砧硬化后的稳定形态。

主要特点：

- 保留实体型铁砧的移动、重力、六向布置、浮力和碰撞玩法。
- 外观使用本体硬化树脂的暖灰褐色，而不是通用染色塑料。
- 打开与原版铁砧相同的菜单。
- 单纯修改名称不消耗经验，也不增加附魔惩罚。
- 修复、附魔合并以及同时进行修复和命名时，除免费命名外均遵循原版铁砧体验。
- 不支持 16 色。
- 作为早期塑料设备、密封件和化工部件的材料基础。

### 3.3 硬化树脂锅

硬化树脂锅与硬化树脂铁砧属于同一材料阶段。就是以前模组刚创建的那个塑料锅改成硬化树脂锅名字，硬化树脂锅只是个适配（硬化）树脂铁砧的工具，MC的炼药锅和本体的鱼缸都可以完成冷凝塔以前的树脂加工。

### 3.4 树脂固定色参考

| 材料 | 主要色值参考 | 外观方向 |
| --- | --- | --- |
| 硬化树脂 | #CBC0B2、#BFAE97、#B09370、#9A7956、#5A4123、#453019 | 暖灰褐、硬质、边缘有浅色磨损，深褐用于缝隙和内腔 |
| 树脂块 | #F7E2B3、#F1D594、#EEC878、#E3BA66、#D9AE56、#C89D44 | 蜂蜜金、琥珀感、柔和半透明和弹性高光 |

硬化树脂铁砧和锅应使用硬化树脂物品的配色重画。树脂铁砧应参考树脂块的色彩和透明感，但需要保留清晰的铁砧轮廓。

### 3.5 液态高粘度树脂

液态高粘度树脂由本体树脂与具有增粘、弹性或填充感的材料混合获得。具体配方可以后续决定，现实参考是高填充黏性树脂、增稠树脂和高黏度密封材料。

主要特点：

- 可以倒在世界中。
- 从源头最多流动 2 格。
- 每流动 1 格需要 40 gt。
- 普通实体接触后被完全粘住，无法自行移动。
- 玩家不会完全失去行动能力，而是以类似蜘蛛网中的速度缓慢移动。
- 颜色固定为浓稠的树脂本色，不提供普通染色。
- 既是世界内陷阱和生物控制材料，也是冷凝塔的前置材料。

### 3.6 高粘度树脂块

液态高粘度树脂在锅或鱼缸中经过时移后形成高粘度树脂块。

主要特点：

- 具有本体树脂块的弹跳、减速、生物捕获、发射器捕获、刷怪笼互动、怨恨、时移和树脂撼地底座效果。
- 可以捕获任意大体型生物，不受本体树脂块的宽度和高度限制。
- 敌对生物仍需要虚弱效果，保证捕获玩法有准备过程。
- 怨恨值保持 0-100 的可读范围：基础情绪、负面效果和受伤程度共同决定数值，并影响后续怨恨琥珀相关结果。
- 是冷凝塔结构的关键材料，使树脂阶段自然连接到原油化工。
- 外观比普通树脂块更深、更浑浊，突出“高填充、难流动、能承受大型结构”的感觉。
- 不支持 16 色。

## 4. 冷凝塔与原油化工

### 4.1 冷凝塔定位

冷凝塔是开启原油化工的核心大型结构。

结构方向：

- 每个冷凝塔模块为 3x3x3。
- 主体由切制重铁块、控制阀和重型铁活板门构成。
- 高粘度树脂块位于结构关键位置，承担密封、减震和树脂化工门槛。
- 控制阀沿两个水平轴布置，外观上表现不同流向。
- 冷凝塔可以在大型炼药锅上方向上堆叠多个模块。
- 手持冷凝塔时，瞄准大型炼药锅顶部应显示完整结构轮廓，方便判断空间和继续向上堆叠。

冷凝塔不是普通机器方块，而是一座玩家能从外观读懂流向、高度和输出层的世界内化工建筑。

### 4.2 等离子喷流气化

推荐布局：

~~~text
冷凝塔上层
冷凝塔下层
大型炼药锅：装待加工原油
等离子喷流顶部：紧贴大型炼药锅底面
等离子喷流柱
喷流燃料锅
加热器
~~~

主要表现：

- 大型炼药锅下方紧贴有效等离子喷流时，锅内原油持续气化。
- 每条有效喷流提供 50 mB/gt 的原油气化速度。
- 多条喷流同时接触大型炼药锅底部时，速度按喷流数量增加。
- 上方没有可工作的冷凝塔或输出受阻时，锅和塔应表现出明显的蒸气积压，而不是安静地继续运行。
- 玩家可以通过液面下降、蒸气、冷凝滴落、阀门状态和声音判断产线是否正常。

燃料锅和加工锅在玩法上是两个不同容器：一个维持喷流，一个处理原油。

### 4.3 分层冷凝

蒸气从大型炼药锅进入最低层冷凝塔，再逐层向上。不同高度收集不同性质的产物。

| 冷凝方向 | 产物定位 | 主要用途 |
| --- | --- | --- |
| 低层重质产物 | 重质馏分、润滑和密封原料 | 润滑机械、制作防黏衬层、补充高粘度树脂、作为高热燃料 |
| 中层塑料原料 | 塑料加工的主要原料 | 生产通用塑料，并继续制作透明、工程和耐热材料 |
| 高层轻质产物 | 轻质燃料和清洗剂 | 为化工设备供能、清洗油污和回收料、处理表面涂层 |
| 顶层挥发产物 | 可压缩气体或发泡介质 | 发泡塑料、吹塑、辅助燃料或安全排放 |

每种独立产物都应拥有至少两种用途。若某种产物只会立即进入下一道加工，则更适合表现为塔内状态，而不是增加新的搬运物品。

### 4.4 冷凝塔的扩展方向

冷凝塔堆叠的意义可以来自：

- 增加可收集的产物种类；
- 提高某一产物的纯度或收率；
- 增加蒸气缓存和连续生产能力；
- 允许玩家选择更偏向塑料原料、燃料或清洗剂的塔层组合；
- 让透明观察件、工程阀门、耐热衬层和超限部件在后续继续升级同一座塔。

## 5. 塑料加工产线

### 5.1 产线总览

~~~text
冷凝塔塑料原料
  -> 塑料基础料
  -> 配混与添加剂
  -> 本色或着色粒料
  -> 加热成型
  -> 塑料制品
  -> 使用与回收
  -> 再生粒料
~~~

游戏中不需要分别制造所有现实单体。玩家需要理解的只有：

- 冷凝塔得到适合制作塑料的原料；
- 原料经过塑料化加工成为可成型材料；
- 添加颜料、增强材料或功能填料会得到不同塑料；
- 粒料被加热后可以压塑、注塑、挤出或热成型；
- 热塑性塑料可以回收，但混色、混料和污染会降低品质。

### 5.2 产线内容方向

| 加工环节 | 世界内内容 | 适合产出的形态 |
| --- | --- | --- |
| 配混 | 塑料锅、大型炼药锅、颜料和功能添加物 | 本色料、着色料、增强料、透明料 |
| 造粒 | 冷却、挤出和切粒 | 便于运输和自动化的塑料粒 |
| 压塑 | 模具与铁砧压力 | 厚板、衬层、结构件、锅和大型部件 |
| 注塑 | 熔融材料进入封闭模具 | 齿轮、外壳、接头、精密零件 |
| 挤出 | 连续通过固定形状出口 | 管、棒、板、膜和线材 |
| 吹塑/热成型 | 中空或薄片材料成型 | 瓶、桶、浮筒、托盘和面板 |
| 回收 | 分选、清洗、粉碎、熔融和再造粒 | 再生料、低级混杂料和填充材料 |

不要求一次加入全部工艺。每种工艺应在拥有足够产品方向时再成为正式内容。

### 5.3 通用塑料

通用塑料是玩家通过原油化工首先稳定量产的塑料，现实外观和主要属性参考 HDPE。

主要特点：

- 乳白或半透明的蜡感表面；
- 耐油、耐多数普通化工流体；
- 抗冲击、轻便、可浮水；
- 易于制成管、容器、板材和中空件；
- 适合作为后续塑料加工设备的管路、密封、护罩和内衬；
- 支持 natural + 16 colors。

推荐内容方向：

- 耐油管和流体接头；
- 储液容器、浮筒和防水建筑件；
- 通用板、棒和薄膜；
- 化工设备护罩、密封圈和可替换内衬；
- 后续复合塑料所需的基础塑料零件。

通用塑料不必立即拥有铁砧。是否需要塑料铁砧、锅或其他大型制品，可根据后续玩法再决定。

## 6. 塑料横向分支

塑料阶段不只是一条不断升级数值的直线。玩家可以根据本体进度，把不同塑料与不同 AnvilCraft 材料结合，制作具有专门用途的复合塑料。

每条复合分支都应同时考虑：

- **强度：** 是否更耐冲击、磨损、冷热或化学腐蚀；
- **功能：** 是否开启新的加工、自动化、光学、热学或电气能力；
- **舒适度：** 是否更轻、更安静、更安全、更易观察或更少维护。

以下方向均为候选材料族，不代表每一族都需要完整物品套装。

### 6.1 皇家工程复合塑料

**组合方向：** 工程塑料 + 皇家钢部件

**现实参考：** ABS、PA、POM 等工程塑料与金属嵌件、骨架或轴套的复合结构。

**强度提升：**

- 皇家钢提供承力骨架和尺寸稳定性；
- 工程塑料吸收冲击并降低金属直接磨损；
- 适合高频运动、连续落砧和精密设备。

**功能提升：**

- 可用于齿轮、轴承、滑块、导轨、模具座和机器外壳；
- 适合制作更稳定的流体阀门和自动化连接件；
- 可以成为皇家钢机器的轻量化升级材料。

**舒适度提升：**

- 降低机构摩擦、噪声和碰撞震动；
- 让手持工具或便携部件更轻；
- 减少精密结构卡住和频繁维护的情况。

**外观方向：** 细颗粒哑光塑料包覆皇家钢骨架。塑料主体可以染色，皇家钢嵌件保留本体标志色。

### 6.2 余烬耐热复合塑料

**组合方向：** 耐热塑料 + 余烬金属、余烬玻璃或余烬设备部件

**现实参考：** PEEK、PTFE 等耐热塑料与耐高温金属、玻纤或矿物填料的复合结构。

**强度提升：**

- 高温和火焰附近不软化；
- 长时间接触热流体时不易损坏；
- 在普通塑料会焦化的环境中保持形状。

**功能提升：**

- 可用于等离子喷流附近的护罩、密封和管路；
- 可作为大型炼药锅、冷凝塔和高温容器的低附着内衬；
- 适合制作耐火储存件、热处理模具和余烬设备外壳。

**舒适度提升：**

- 减少锅壁残留和清理频率；
- 制作隔热握柄、护套和安全踏板；
- 降低玩家接近高温设备时的操作风险。

**外观方向：** 浅色耐热塑料与余烬橙红金属相间，局部呈现受热高光，但不表现为整件持续发光。

### 6.3 浮霜低温复合塑料

**组合方向：** 低温韧性塑料 + 浮霜金属、浮霜玻璃或冷却部件

**现实参考：** 低温环境使用的抗冲击聚乙烯、弹性改性塑料和保温泡沫。

**强度提升：**

- 在严寒和冷却流体附近不脆裂；
- 抵抗冷热循环造成的开裂；
- 保持密封件和软管的柔韧性。

**功能提升：**

- 可用于冷却管、低温容器、保温层和浮霜设备外壳；
- 可以延长冷却状态或减少外界热量进入；
- 适合发展冷藏、低温运输和冷热转换支线。

**舒适度提升：**

- 减少设备结冰和堵塞；
- 降低玩家接触低温设备时的减速或冻伤压力；
- 让冷热产线更容易同时布置。

**外观方向：** 淡蓝、雾白和半透明塑料包覆浮霜金属，表面保持干净冷光而不是厚重冰层。

### 6.4 宝石光学复合塑料

**组合方向：** 透明塑料 + 红宝石光学件、蓝宝石/黄玉材料、钢化玻璃或特殊镜片

**现实参考：** PC、PMMA 光学塑料与硬质涂层、滤光材料和玻璃镜片的复合件。

**强度提升：**

- 比普通玻璃更轻、更耐冲击；
- 表面加入宝石或玻璃层后更耐划伤；
- 适合透明容器、观察窗和移动光学件。

**功能提升：**

- 可制作激光导光件、滤光片、镜片外壳和观察组件；
- 不同宝石或玻璃可以赋予不同光学倾向；
- 可以让冷凝塔、流体管和机器状态直接可见。

**舒适度提升：**

- 玩家无需打开界面即可观察液位、堵塞、温度倾向或工作状态；
- 透明件更轻，破损时比玻璃更安全；
- 颜色和光学标记可以帮助区分不同管线。

**外观方向：** 高透明塑料主体配宝石色边缘、镜片或镀层。natural 为无色透明，染色版本保持透光感。

### 6.5 弹性缓冲复合塑料

**组合方向：** 弹性塑料 + 树脂、黏液材料或皇家钢承力件

**现实参考：** TPE、EVA、橡胶包覆件、减震垫和金属橡胶复合结构。

**强度提升：**

- 承受反复弯曲和冲击；
- 保护内部脆弱部件；
- 在运输和落砧环境中减少瞬间损坏。

**功能提升：**

- 可用于缓冲底座、运输防撞件、弹性接头和减震模具；
- 可以扩展弹跳、低伤害落地和实体推动玩法；
- 适合作为大型机器之间的减震连接层。

**舒适度提升：**

- 降低震动、噪声和击退；
- 减少玩家站在大型设备附近时的屏幕震动或失控感；
- 提供更柔和的运输和落地体验。

**外观方向：** 柔和哑光或半透明材质，受压区域有明显形变感，金属骨架只在承力位置露出。

### 6.6 电气复合塑料

**组合方向：** 绝缘塑料 + 硬化树脂 + 铜、红石、黄玉或本体电气部件

**现实参考：** 电气级塑料、绝缘层、导电填料塑料和包覆电缆。

**强度提升：**

- 隔离潮湿、油污和普通热量对电气部件的影响；
- 保护内部线圈、红石元件和连接端；
- 减少机械碰撞造成的短路或失效。

**功能提升：**

- 可用于线缆护套、充能设备外壳、传感器和安全连接器；
- 普通绝缘塑料负责隔离，特殊导电复合料负责可控传导；
- 透明电气塑料可以显示充能或过载状态。

**舒适度提升：**

- 减少误触和意外放电；
- 用颜色清楚区分能量、控制和流体线路；
- 降低复杂设备布线和维护时的辨认成本。

**外观方向：** 深色或浅灰塑料壳体配铜色、红石红或黄玉黄色功能纹路。功能色不必等同普通染色。

### 6.7 横向分支关系

这些分支可以互相交叉：

- 工程塑料可以同时拥有皇家钢骨架和绝缘外层；
- 透明塑料可以制作余烬或浮霜环境的观察窗；
- 耐热塑料可以加入工程增强，制作高温运动部件；
- 弹性塑料可以成为光学件和电气件的防震包覆；
- 同一种本体材料也可以与不同塑料形成功能不同的复合物。

复合塑料的价值在于“为具体用途选择材料”，而不是形成一个全面优于所有塑料的新等级。

## 7. 超限塑料

超限塑料是 Plasticraft 的最终材料等级。它由高级复合塑料与本体超限合金、多相物质或多相超限材料结合。

### 7.1 核心特点

- 继承所选复合塑料最重要的功能，而不是把所有分支能力全部叠加。
- 可表现轻相与重相、柔性与刚性、隔热与导热等可切换状态。
- 具有终局级耐久、耐热、耐化学和环境适应能力。
- 外观应同时保留塑料主体、多相变化和超限材料的标志性颜色。
- 主要价值是让本体超限阶段的设备和工具获得新的使用方式与舒适度。

### 7.2 内容方向

超限塑料适合考虑：

- 能在轻量运输与重型工作之间切换的部件；
- 极端冷热环境通用的化工容器和管路；
- 几乎不需维护的终局设备内衬、密封和轴承；
- 可改变透明度、质量或碰撞特性的多相结构件；
- 与超限工具结合的握柄、护罩、精密模式或安全模式；
- 只有在玩法确实需要时才加入超限塑料铁砧。

超限塑料不必是万能材料。切换状态、材料选择或设备用途应继续保留取舍。

## 8. 塑料颜色与染色

### 8.1 颜色范围

颜色能力按材料选择，而不是所有塑料统一拥有。

| 材料方向 | 推荐颜色范围 | 说明 |
| --- | --- | --- |
| 树脂铁砧、硬化树脂铁砧和锅 | 固定本色 | 保留本体树脂身份 |
| 液态/块状高粘度树脂 | 固定本色 | 颜色用于表达黏度和结构强度 |
| 通用塑料 | natural + 16 colors | 适合建筑、管线和通用制品 |
| 透明塑料 | natural + 16 colors | natural 为无色透明，染色后仍保持透明感 |
| 工程塑料 | natural + 16 colors | 适合机器外壳和管线识别 |
| 耐热、低温、电气塑料 | 根据具体制品选择 | 功能识别色可以高于装饰染色 |
| 复合塑料 | 选择性支持 | 塑料主体可染，本体材料嵌件保留标志色 |
| 超限塑料 | 固定或专用相态色 | 不默认使用普通 16 色 |

### 8.2 现实染色工艺参考

| 工艺 | 现实特点 | 游戏内容方向 |
| --- | --- | --- |
| 干混颜料 | 设备简单，但分散不均匀 | 早期小批量染色，表面可能有色点 |
| 色母粒 | 颜料浓缩在相容塑料中，再与本色料混合 | 正式批量染色、自动配色和功能添加 |
| 液体色浆 | 通过液体载体计量加入塑料 | 大型炼药锅连续染色 |
| 预着色料 | 原料本身已经均匀着色 | 奖励、贸易或简化获取方向 |
| 透明染料 | 色剂溶入透明塑料，保留透光 | 透明塑料的彩色版本 |
| 表面喷涂/印刷 | 成品表面增加颜色或图案 | 装饰、标记和设备管线识别 |

色母粒只有在同时承担批量染色、功能添加或线路标记时才值得成为独立内容。

### 8.3 贴图和色板方向

每种可染塑料使用自己的灰度纹理，再根据颜色使用不同色板着色。

建议美术层次：

- **主体灰度：** 表达蜡感、哑光、透明、纤维或回收颗粒；
- **着色区域：** 只改变塑料主体；
- **固定细节：** 皇家钢、余烬金属、宝石、铜线和开口内壁保留原色；
- **透明层：** 单独表达透明度、透光和雾化；
- **功能纹路：** 电气、余烬、浮霜或超限状态使用专用视觉，不等同普通染料。

natural 是未加颜料的材料本色，white 是加入白色颜料后的颜色，两者不能混为同一状态。

## 9. 现实塑料参考

### 9.1 按受热行为分类

| 现实类别 | 主要特点 | 可参考的游戏方向 |
| --- | --- | --- |
| 热塑性塑料 | 加热软化、冷却硬化，可以再次成型 | 通用塑料、透明塑料、工程塑料及机械回收 |
| 热固性塑料 | 固化后不再熔化，只会焦化或分解 | 硬化树脂、耐热固化件和不可重熔复合物 |
| 弹性体 | 变形后恢复，擅长缓冲和密封 | 树脂铁砧、弹性塑料、减震和软连接 |

### 9.2 现实材料与游戏属性

| 现实材料参考 | 现实外观/特性 | 游戏材料方向 |
| --- | --- | --- |
| HDPE | 乳白、蜡感、耐油、抗冲击、可浮水 | 通用塑料 |
| PP / LDPE | 轻、柔韧、耐疲劳 | 薄膜、软管、铰链和轻量制品参考 |
| PET / PC / PMMA | 透明、可做光学件，强度和耐划伤各有差异 | 透明塑料和宝石光学复合塑料 |
| ABS / PA / POM | 工程件、耐冲击、耐磨或低摩擦 | 工程塑料和皇家工程复合塑料 |
| PTFE / PEEK | 耐热、耐化学、低附着 | 耐热塑料和余烬耐热复合塑料 |
| TPE / EVA / 橡胶 | 弹性、缓冲、密封和减震 | 弹性缓冲复合塑料 |
| 玻纤/矿物增强塑料 | 更硬、更稳定，但更重且更难回收 | 皇家钢、余烬或浮霜增强塑料的外观与取舍参考 |
| 电气级塑料 | 绝缘、阻燃、保护电气结构 | 电气复合塑料 |

现实名称用于决定外观和最主要的游戏特性，不要求玩家区分具体牌号、单体、压力或精确温度。

### 9.3 现实塑料加工参考

| 工艺 | 现实用途 | 适合的模组内容 |

## 10. 暂不固定的内容

以下内容保留给后续设计决定：

- 每种塑料最终拥有哪几种物品或方块；
- 哪些塑料需要铁砧、锅、容器、工具或完整设备；
- 冷凝塔每层的具体产率、配比和产物数量；
- 塑料加工设备最终采用哪些世界内结构；
- 各种复合塑料具体制作哪些本体设备升级件；
- 哪些复合塑料支持 natural + 16 colors；
- 超限塑料是否拥有铁砧，以及相态切换作用在哪些物品上；
- 各材料特性的具体数值强度。

确定新内容时，优先选择能同时体现材料特点、连接本体主线并改善玩家体验的制品。
